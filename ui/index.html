Envoi dans le micro

Streamee pose un petit filtre audio sur ton micro : les sons partent avec ta voix dans tous les jeux, Discord ou OBS, sans micro virtuel. Windows demandera l'autorisation administrateur et le son sera coupé deux secondes le temps de redémarrer le service audio.
